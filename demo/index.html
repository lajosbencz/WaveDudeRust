WaveDude Rust

GitHub source | GitHub releases

A desktop app for Linux, macOS and Windows that simulates how waves travel, bend and interfere: draw a scene of light sources, lenses, mirrors and walls, watch the waves move through it, measure them with probes and export the result as a video.

This is an in-browser demo! The goal is to demonstrate the portability of the codebase. It plays examples and your .wdproj files, but cannot edit, save or export.
