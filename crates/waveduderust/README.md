# waveduderust

2D wave simulation library behind [WaveDude Rust](https://github.com/lajosbencz/WaveDudeRust): project model, file
formats, scene painting, CPU and wgpu engines, background runs, rendering and exports.

- API: [docs.rs/waveduderust](https://docs.rs/waveduderust)
- Features and stability (`unstable-*` modules follow no semver): [decision 0032](https://github.com/lajosbencz/WaveDudeRust/blob/master/docs/decisions/0032-slint-single-frontend.md)
- Physics: [docs/physics.md](https://github.com/lajosbencz/WaveDudeRust/blob/master/docs/physics.md)
